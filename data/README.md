# data/ — 数据集根目录（M2 填充，不入库）

全部使用**网络真实数据**（ADR-3）：软件名搜索截图 / 真实照片，不用合成数据。

```
data/
├── raw/                     # 用户手工收集的原始图片（不入库）
│   ├── l1/
│   │   ├── content/         # 照片/CG/插画/画作（目标 1000 张）
│   │   └── structure/       # 纯文本/表单/UI/网页/文档（目标 1000 张）
│   └── l2/
│       ├── ui/              # 软件界面/网页截图（目标 1000 张）
│       ├── text/            # 纯文本/文档页截图（目标 1000 张）
│       └── form/            # 表单/表格截图（目标 1000 张）
└── yolo/                    # train/data.py 生成的 YOLO 分类数据集（train 800 + val 200）
```

收集来源建议：搜索引擎图片（按软件名/关键词）、真实应用截图（本机各软件窗口）、
公共图片数据集子集。收集脚本见 `scripts/download-data.ps1`（占位，M2 完善）。
